# ✏️ Text Editor

**Кроссплатформенный текстовый редактор**  
Разработан на **C++17** с использованием **Qt6**.

> Простой, быстрый и удобный инструмент для работы с текстом.

---

## 🚀 Особенности

- Поддержка основных операций: открытие, сохранение, редактирование
- Кроссплатформенность: Windows, Linux, macOS
- Чистый и интуитивно понятный интерфейс

---

## 🛠️ Технологии

- **C++17** – современный стандарт языка
- **Qt6** – фреймворк для создания графических приложений
